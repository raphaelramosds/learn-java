# Learn Java

## Notes

1. Never delete the directory `nbproject/` because it stores the Netbeans project setup
2. Execute the Java Swing projects of this repo on Netbeans IDE 20 and Java 21
3. Download and install a Apache Tomcat server to run the Java Servlet projects of this repo. You can download it from [here](https://tomcat.apache.org/tomcat-8.5-doc/introduction.html)

## How to execute Java code

Say your file is YourCode.java

### Compile

```
javac YourCode.java
```

### Run it

```
java YourCode
```
